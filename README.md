# CYB Mobile Barber & Tattoo - Admin Dashboard & Frontend

Repositori ini berisi kode sumber (*source code*) untuk website publik serta sistem panel Admin Dashboard dari layanan privat (Tattoo, Piercing, dan Mobile Grooming).

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Dark-Mode Design System), JavaScript (Vanilla JS routing)
* **Design Identity:** Minimalist Dark-Mode (Solid black `#000000`, muted gold `#C5A059` accents, and signature diamond `◇` border accents).

## 📂 Struktur File Proyek
* `index.html` - Halaman utama / Landing page publik.
* `login.html` - Halaman autentikasi/login admin.
* `admin.html` - Halaman utama Dashboard Overview (Statistik & Metrik).
* `appointments.html` - Halaman manajemen pesanan klien (Tabel & Status).
* `pricing.html` - Halaman pengaturan layanan dan harga (*Services & Pricing*).
* `styles.css` / `admin.css` / `login.css` - File lembar gaya (*stylesheet*).
* `script.js` / `admin.js` / `login.js` - Logika interaksi dan navigasi halaman.
